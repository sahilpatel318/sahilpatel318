# `04` - Selected Projects

## 🔎 Control Gap

**Python · LangGraph · OpenAI API · FastAPI · RAG**

A regulatory-control analysis system designed to identify where internal controls may fail to address external requirements.

* Built a pipeline mapping **regulatory requirements against internal controls**
* Designed evidence-grounded verification to improve **traceability**
* Achieved **1.0 gap-detection recall** across 25 hand-labelled regulatory requirements

> **Idea:** AI-generated findings should be traceable back to evidence — not treated as a black box.

---

## 🛡️ Control Effectiveness Backtester

**Python · TF-IDF · HTML/CSS · JavaScript**

A system for testing whether documented controls appear effective against historical incidents.

* Evaluated **140 incidents against 22 controls**
* Classified control failures using evidence-based categories
* Achieved **0.86 failure-detection precision**
* Identified ineffective controls and areas of uncovered risk

> **Idea:** Controls shouldn't only exist on paper — their effectiveness should be measurable.

---

## 🧭 PIICompass

**Python · FastAPI · AST Static Analysis · SQL**

A privacy-focused static-analysis tool for understanding how sensitive information moves through application schemas.

* Mapped sensitive-data flows across application structures
* Flagged **special-category data** and **cross-border transfers**
* Achieved **0.93 F1** against sealed ground truth across 48 schema columns

> **Idea:** Privacy becomes easier to manage when data movement becomes visible.

---

## 📈 Leading-Indicator Engine

**Python · LangChain · OpenAI API · Streamlit**

An analytics system designed to find signals that appear before operational failures.

* Identified complaint themes associated with future operational issues
* Recovered **five planted indicators with zero false positives**
* Backtested alerts with **78–94% precision**, compared with a 16% base rate

> **Idea:** The most useful analytics don't only explain what happened — they help identify what may happen next.

---

## 🔄 Purchase-to-Pay Process Mining

**Python · Process Mining · Event-Log Analysis · LLM Guardrails**

An event-log analytics project examining how a purchase-to-pay process behaves in practice.

* Analyzed **1,000 cases and 8,668 events**
* Identified **495 process deviations**
* Detected **33% rework**
* Quantified a **9.5-day payment delay**
* Converted event data into actionable process-improvement findings

> **Idea:** Real processes rarely behave exactly like their documented workflows.
